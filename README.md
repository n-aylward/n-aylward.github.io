# n-aylward.github.io

Personal resume site—a static [Astro](https://astro.build) app deployed to GitHub Pages. Resume and contact data in `src/data/` power the webpage and DOCX download. Headless Chrome generates the PDF by printing the built webpage.

Live: https://n-aylward.github.io/

## Quick start

Requires Node 22 (see `.node-version`).

```bash
npm install
npm run dev
```

## Editing the resume

Resume content lives in `src/data/resume.ts` (skills, experience, education) and `src/data/contacts.ts` (email, LinkedIn, GitHub). Edit those files, then run `npm run build` to regenerate the webpage, PDF, and DOCX.

## Scripts

| Command                           | What it does                                   |
| --------------------------------- | ---------------------------------------------- |
| `npm run dev`                     | Astro dev server with hot reload               |
| `npm run build`                   | Full build: DOCX, type-check, static site, PDF |
| `npm run resume:docx`             | Just the DOCX                                  |
| `npm run resume:pdf`              | Just the PDF                                   |
| `npm run validate`                | Check the resume data has all required fields  |
| `npm run format` / `format:check` | Prettier                                       |
| `npm run lint`                    | ESLint                                         |

The PDF is normally generated by printing the built webpage with headless Chrome, using the site's print styles. If Chrome can't launch, the generator copies the checked-in PDF as a fallback, which may be stale. After resume or print-style changes, run the build in a Chrome-capable environment and commit the regenerated PDF.

## Deployment

Pushes to `main` and manual dispatches run `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages.

Pull requests and pushes to `main` run `.github/workflows/test.yml`. On pull requests, the workflow deploys a Cloudflare Pages preview and runs pa11y (WCAG 2 AA) and linkinator against it. These checks require `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`. GitHub doesn't provide repository secrets to forked pull requests, so the preview step fails for them.


comments in TypeScript, JavaScript, and CSS files.
